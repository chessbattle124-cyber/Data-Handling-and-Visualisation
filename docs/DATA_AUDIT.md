## Scope limitation
The supplied file has overall Score and Rank, but no TLR, RPC, GO, OI or Perception parameter scores. Therefore, the PDF's parameter-correlation and five-parameter comparison questions cannot be answered from this dataset. The app must state this instead of manufacturing values.

Rows marked withdrawn or without numeric ranks are excluded from rank-movement calculations. Missing scores remain null, not zero.
